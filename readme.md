# 📒 NoteHub

**NoteHub** is a solo, cross-platform note-taking application designed to help users organize ideas and stay productive across web and mobile platforms.

Currently, NoteHub includes:

- 🌐 **Web App** built with **Angular**
- 📱 **Mobile App** built with **React Native**

A **Spring Boot backend** is planned and will be integrated in a future phase.

---

## 🚀 Features

- Create, edit, and manage notes
- Clean and intuitive user interface
- Cross-platform experience (Web & Mobile)
- Scalable architecture designed for future backend integration

---

## 🛠 Tech Stack

### Frontend (Web)

- Angular
- TypeScript
- HTML & CSS

### Mobile

- React Native
- JavaScript / TypeScript

### Backend (Planned)

- Spring Boot
- REST APIs
- Authentication & data persistence
